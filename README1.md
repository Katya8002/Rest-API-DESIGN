# Що приготувати?

Сайт, який підказує, що можна приготувати з продуктів, що вже є у вас у холодильнику.

## Про проєкт

Часто в холодильнику є кілька продуктів, а що з них приготувати — незрозуміло. Цей сайт вирішує проблему.

Користувач веде список продуктів у своєму холодильнику: що саме є, скільки, до якої дати воно придатне. Сайт порівнює цей список із каталогом рецептів і показує:

- які страви можна приготувати **просто зараз**;
- для решти страв — **чого саме не вистачає**.

### Що є на сайті

- **Каталог рецептів** з пошуком за назвою та фільтрами (категорія, час приготування, продукт).
- **Сторінка рецепта**: опис, час приготування, список інгредієнтів із кількістю, кроки приготування.
- **Довідник продуктів** (молоко, яйця, борошно тощо) з одиницею виміру.
- **Категорії страв** (сніданки, супи, десерти тощо). На сторінці категорії видно всі її рецепти.
- **Додавання, редагування й видалення** рецептів, продуктів і категорій.
- **Реєстрація та вхід**.
- **Профіль користувача**: перегляд і редагування даних про себе, історія приготованих страв.
- **Мій холодильник**: продукти користувача, їх кількість і термін придатності.
- Кнопка **«Приготувала»** на сторінці рецепта: додає страву до історії. Продукти з холодильника при цьому автоматично не списуються (спрощена версія).
- Сторінка **«Про сайт»** з контактною інформацією.

## REST API

### Загальні правила

- Базовий префікс усіх запитів: `/api/v1`
- Усі дані передаються у форматі **JSON**.
- Назви ресурсів у множині, дію задає HTTP-метод (`GET`, `POST`, `PUT`, `DELETE`).
- Списки підтримують пагінацію: `?page=1&limit=20`.
- Помилки повертаються у форматі: `{"detail": "опис помилки"}`.
- Успішне видалення повертає `204` без тіла.
- Без авторизації доступні лише: `POST /auth/register`, `POST /auth/login`, `GET /products`, `GET /products/{id}`, `GET /categories`, `GET /categories/{id}`, `GET /recipes` (без `can_cook`), `GET /recipes/{id}`, `GET /about`. Усі інші ендпоінти потребують авторизації. API не зберігає стан між запитами, тому дані авторизації передаються в кожному запиті (заголовок `Authorization`).
  
### Авторизація та профіль

| Метод і URL | Призначення | Body / параметри | Успішна відповідь | Помилки |
|---|---|---|---|---|
| `POST /auth/register` | Реєстрація | `{"username", "email", "password"}` | `201` + дані користувача | `400`|
| `POST /auth/login` | Вхід | `{"email", "password"}` | `200` + дані для авторизації (**TBD**) | `401` |
| `GET /users/me`  | Мій профіль | — | `200` + дані користувача | `401` |
| `PUT /users/me`  | Змінити дані про себе | `{"username", "email"}` | `200` + оновлені дані | `400`, `401`|


### Продукти (довідник)

| Метод і URL | Призначення | Body / параметри | Успішна відповідь | Помилки |
|---|---|---|---|---|
| `GET /products` | Список продуктів | `?search=молоко&page=1&limit=20` | `200` + список | — |
| `GET /products/{id}` | Один продукт | — | `200` + продукт | `404` |
| `POST /products`  | Додати продукт | `{"name", "unit"}` | `201` + створений продукт | `400`, `401` |
| `PUT /products/{id}` | Змінити продукт | `{"name", "unit"}` | `200` + оновлений продукт | `400`, `401`, `404` |
| `DELETE /products/{id}` | Видалити продукт | — | `204` | `401`, `404` |


### Категорії страв

| Метод і URL | Призначення | Body / параметри | Успішна відповідь | Помилки |
|---|---|---|---|---|
| `GET /categories` | Список категорій | — | `200` + список | — |
| `GET /categories/{id}` | Категорія з її рецептами | — | `200` + категорія зі списком рецептів | `404` |
| `POST /categories`  | Додати категорію | `{"name"}` | `201` + створена категорія | `400`, `401` |
| `PUT /categories/{id}`  | Змінити категорію | `{"name"}` | `200` + оновлена категорія | `400`, `401`, `404` |
| `DELETE /categories/{id}`  | Видалити категорію | — | `204` | `401`, `404` |


### Рецепти

| Метод і URL | Призначення | Body / параметри | Успішна відповідь | Помилки |
|---|---|---|---|---|
| `GET /recipes` | Список рецептів | `?search=омлет&category_id=1&max_time=30&product_id=2&page=1&limit=20` | `200` + список | — |
| `GET /recipes?can_cook=true`  | Лише рецепти, які можна приготувати з мого холодильника | ті самі параметри + `can_cook=true` | `200` + список | `401` |
| `GET /recipes/{id}` | Сторінка рецепта | — | `200` + рецепт | `404` |
| `POST /recipes`  | Додати рецепт | див. приклад нижче | `201` + створений рецепт | `400`, `401` |
| `PUT /recipes/{id}`  | Змінити рецепт | як у `POST` | `200` + оновлений рецепт | `400`, `401`, `404` |
| `DELETE /recipes/{id}`  | Видалити рецепт | — | `204` | `401`, `404` |



Тіло запиту `POST /recipes` (і `PUT /recipes/{id}`):

```json
{
  "name": "Омлет",
  "description": "Швидкий сніданок",
  "cooking_time_min": 15,
  "category_id": 1,
  "steps": [
    "Збити яйця з молоком",
    "Смажити на середньому вогні"
  ],
  "ingredients": [
    {"product_id": 1, "quantity": 3},
    {"product_id": 2, "quantity": 100}
  ]
}
```


Відповідь `GET /recipes/3`. Поле `missing_ingredients` присутнє лише для авторизованих користувачів і показує, чого не вистачає саме їм:

```json
{
  "id": 3,
  "name": "Омлет",
  "description": "Швидкий сніданок",
  "cooking_time_min": 15,
  "category": {"id": 1, "name": "Сніданки"},
  "steps": [
    "Збити яйця з молоком",
    "Смажити на середньому вогні"
  ],
  "ingredients": [
    {"product": {"id": 1, "name": "Яйця", "unit": "pcs"}, "quantity": 3},
    {"product": {"id": 2, "name": "Молоко", "unit": "ml"}, "quantity": 100}
  ],
  "missing_ingredients": [
    {"product_id": 2, "name": "Молоко", "needed": 100, "in_fridge": 0, "unit": "ml"}
  ]
}
```

### Мій холодильник

| Метод і URL | Призначення | Body / параметри | Успішна відповідь | Помилки |
|---|---|---|---|---|
| `GET /fridge/items` | Що зараз є в холодильнику | — | `200` + список | `401` |
| `POST /fridge/items`  | Додати продукт у холодильник | `{"product_id", "quantity", "expires_at"}` | `201` + створений запис | `400`, `401`, `404` (немає такого продукту) |
| `PUT /fridge/items/{id}`  | Змінити кількість або термін придатності | `{"quantity", "expires_at"}` | `200` + оновлений запис | `400`, `401`, `404` |
| `DELETE /fridge/items/{id}`  | Прибрати продукт із холодильника | — | `204` | `401`, `404` |

Тіло запиту `POST /fridge/items`:

```json
{
  "product_id": 1,
  "quantity": 6,
  "expires_at": "2026-10-20"
}
```

Відповідь `201`:

```json
{
  "id": 7,
  "product": {"id": 1, "name": "Яйця", "unit": "pcs"},
  "quantity": 6,
  "expires_at": "2026-10-20"
}
```
